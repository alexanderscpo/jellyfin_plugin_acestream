Base URL of the acexy proxy used for playback (multiplexing + per-client pid).
Base URL of the AceStream engine used for search/browse (/search).
How long ffprobe analyzes a live stream to detect its codecs. Lower starts faster; higher is more robust on slow channels. Default 5000.
How long discovered codecs are cached per channel so repeat plays skip the readiness check and ffprobe. Set to 0 to disable the cache. Default 5.
How long to wait for the AceStream engine session to reach "downloading" state before the channel is declared not ready and the codec probe is skipped. A cold start takes 15–25 s; keep above 30 for best results. Default 30.
Paste an M3U playlist with acestream:// URIs and/or http(s) URLs pointing to .acelive transport files. Channels appear in a "Custom" folder in the browser. Standard #EXTINF headers are supported; other entries are ignored.
.acelive URLs are resolved automatically on play — recommended for private broadcasts. If you use a raw 40-hex id instead, it must be the stream's infohash; the engine's get_content_id value is not the infohash and will not play.
